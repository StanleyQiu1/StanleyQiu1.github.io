ALTIMETER.

An earlier ESP32 project using a BMP180 pressure sensor to experiment with atmospheric pressure and altitude measurement.

Year 2024
Status Prototype
Overview

TURNING PRESSURE INTO ALTITUDE.

This project uses an ESP32 and BMP180 pressure sensor.

It was an early experiment with sensors, embedded programming and converting physical measurements into useful data.

ESP32 BMP180 Arduino IDE CAD
Controller ESP32
Sensor BMP180
Measures Pressure / Altitude
Year 2024
Design

SENSOR DATA BECOMES INFORMATION.

The BMP180 measures atmospheric pressure. The ESP32 reads this information and can use the pressure measurement to estimate altitude.

This project helped me become more familiar with interfacing sensors with microcontrollers.
