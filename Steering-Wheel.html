GILBERT SYSTEM
STEERING WHEEL

This is the steering wheel PCB of the Gilbert System.

Year 2026
Project Solar Car
Overview

ELECTRONICS FOR A SOLAR CAR.

This board contains an STM32G071KBT6N, an AP63203WU buck converter (12V-3V3), a LSM6DSL IMU, and 10 keyboard switches. I used keyboard switches as requested by my team, as they function the same as typical buttons and make the PCB wheel system different from others.

I used an STLink V2 to program this board, but I bought a clone and the 3V3 output stopped working which was very annoying.

STM32CubeIDE STM32 RS485

Software Python / STM32CubeIDE
