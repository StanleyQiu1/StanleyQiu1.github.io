Overview

A SMALL SATELLITE AS A BIG SYSTEMS PROJECT.

This project is based around a CubeSat-style structure containing multiple stacked PCBs.

The image above shows the electrical power system. Additional boards will eventually stack with it to create a larger integrated electronics system.

Architecture

MULTIPLE BOARDS. ONE SYSTEM.

Instead of putting everything on one PCB, the project uses separate boards for different functions.

This makes the project an exercise in system architecture as well as individual circuit design.

EPS

POWER COMES FIRST.

The electrical power system manages how energy enters, is stored and is distributed through the CubeSat.

Designing the EPS has required thinking about solar input, battery power, voltage regulation, current monitoring and how the other boards will receive power.

01

Power Input

The system has to accept energy from external sources while protecting downstream electronics.

02

Battery

Stored energy allows the electronics to operate when solar power is not available.

03

Power Rails

Different subsystems require stable regulated voltages.

04

Monitoring

Current and voltage monitoring can provide information about how the power system is behaving.

Future

THE EPS IS ONLY THE BEGINNING.

The next boards will build on the electrical and mechanical interfaces established by the EPS.

The long-term goal is to combine the boards, structure, sensors and software into one working CubeSat-style platform.
