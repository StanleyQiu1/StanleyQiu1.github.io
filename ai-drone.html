BUILDING A PLATFORM FOR AUTONOMOUS EXPERIMENTATION.

This drone is a platform I built to explore flight control, electronics, embedded systems, computer vision and autonomous behavior.

Instead of treating the drone as a finished product, I use it as an experimental system that I can continuously modify and improve.

Development

HARDWARE AND SOFTWARE HAVE TO WORK TOGETHER.

The project involves more than making a frame fly. Flight stability, sensors, control logic, power, weight and software all affect how the system behaves.

My long-term goal is to use this platform for computer vision and autonomous experiments.
