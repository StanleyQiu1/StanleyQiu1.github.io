Overview

NON-FUNCTIONAL MISSILE. 5'8"~ 172.72 CM LONG. 100MM WIDE.

I was bored on a weekend and decided I needed more practice with CAD. I opened Fusion and spent around 7 hours designing this missile. Most of the time was spent on making cutting the main body into different parts so it can fit in my 3D printer.

It is centered on a NodeMCU ESP32S with a breakout board. It uses a OV2640 camera module (one without ribbon cable but with header pins). It uses a PCA9685 servo driver to drive the servos (ESP32 cannot provide enough Amps). There is a 3000mAh 2S LiPo battery powering the system.

ARCHTECTURE: CAMERA -> ESP32 -> WEB BROWSER -> TRACKER MODEL -> ESP32 -> PCA9865 -> SERVOS
