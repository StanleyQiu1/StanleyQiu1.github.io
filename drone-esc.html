Overview

A PROJECT THAT DIDN'T WORK PERFECTLY.

I designed this custom ESC as part of my drone project.

During testing I ran into problems that prevented me from implementing it into the drone. I still consider the project valuable because debugging failures is an important part of engineering.

Design

DESIGNING MOTOR CONTROL HARDWARE.

An ESC has to control significant motor current while responding quickly and reliably to control signals.

This made the project a useful exercise in PCB design, switching electronics, embedded control and hardware testing.
