SYSTEM V3.0

This is the newest version of the 12V system that is going to be implemented in the TCHS Heliotech Advanced Car.

Year 2026
Project Solar Car
Overview

ELECTRONICS FOR A SOLAR CAR.

There are a total of 5 different PCB boards that are going to be connected through RS485 (was going to use CAN but the mppt data is through RS485 so I decided to use it for the whole system instead). 4 of the PCB's have MCUs, all of the STM32 family. The system is going to be powered through Milwaukee M18 batteries bucked down to 12V.

The main difference between this system and the previous system is that this version includes 5 boards instead of 2 and uses mostly SMD components and not through hole. I used direct ICs not devmodules.

Python STM32CubeIDE Telemetry STM32 RS485
Application Solar Car
System 12V PCB System
Software Python / STM32CubeIDE
Focus Telemetry-RS485
System

ONE PART OF A MUCH LARGER MACHINE.

The system has to work around the limited space that is available in the car (the car was designed with only aerodynamics in mind, leaving little room inside the car). This year, the system will be implemented in the front/nose of the vehicle.

The system reads data from one of the 2 MPPTs, 2 IMUs, and 1 temp sensor (to detect overheating). There is one board for the main calculations, 1 acting as a backup (detecting main battery voltage) that runs off of a seperate M18 battery from the main two M18s in parallel, 1 on the steering wheel, 1 acting as a screen, and 1 that contains 14 switches.
