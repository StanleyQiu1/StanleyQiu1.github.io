GILBERT SYSTEM
BACKUP-BOARD

This is the Backup-Board PCB of the Gilbert System.

Year 2026
Project Solar Car
Overview

ELECTRONICS FOR A SOLAR CAR.

This board contains an STM32G030F6P6, two AP63203WU buck converter (12V-3V3), a INA226 Current+Voltage monitor, and an ISO1540 isolator. There also it a screen and buttons, which are able to run the dinosaur game (I added it for fun).

The main function of this board is to monitoir the voltage coming from the main 12V power source and rings an alarm if the detected voltage is below the safe threshold or detects no voltage. It also distributes power to other essential system that are required to power the car, such as powering the contactors (enable power to flow from power to go from solar panels to battery and battery to motor controller).
